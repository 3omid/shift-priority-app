راهنمای اجرا و ساخت فایل نصبی
================================

## سریع‌ترین راه (تست روی ویندوز)
روی run.bat دوبار کلیک کن. توضیح کامل‌تر پایین همین فایل هست.


## ۱) ویندوز — فایل exe واقعی
build-exe.bat رو دوبار کلیک کن.
- بار اول کتابخونه‌ها (از جمله Electron) نصب می‌شن، چند دقیقه طول می‌کشه.
- در پایان یه فایل نصبی (Setup...exe) داخل پوشه "release" ساخته می‌شه.
- همون فایل رو به هر ویندوزی بدی، مستقیم نصب و اجرا می‌شه؛ نیازی به Node.js روی
  کامپیوتر مقصد نیست، چون Electron همه‌چی رو داخل خودش بسته‌بندی می‌کنه.


## ۲) روش مشترک برای آیفون / اندروید / ویندوز — نصب به‌صورت PWA
این تنها روشی است که بدون حساب توسعه‌دهنده (Apple/Google) و بدون کامپایل جداگانه،
روی هر سه پلتفرم "آیکون نرم‌افزار روی صفحه اصلی" می‌سازد و آفلاین هم کار می‌کند.

مراحل:
1. برنامه رو یک‌بار آنلاین در دسترس بذار (مثلاً با یکی از سرویس‌های رایگان مثل
   Vercel، Netlify یا GitHub Pages — کافیه پوشه پروژه رو آپلود کنی، خودشون
   دستور "npm run build" رو اجرا و لینک عمومی می‌دن).
2. روی آیفون: لینک رو در Safari باز کن → دکمه Share → "Add to Home Screen".
3. روی اندروید: لینک رو در Chrome باز کن → منوی سه‌نقطه → "Add to Home screen"
   یا خودش پیشنهاد نصب می‌ده.
4. روی ویندوز: لینک رو در Edge/Chrome باز کن → آیکون نصب کنار نوار آدرس.

بعد از این، برنامه دقیقاً مثل یه اپ واقعی روی صفحه اصلی میاد، بدون نوار آدرس مرورگر.


## ۳) اندروید — فایل APK واقعی (پیشرفته)
این مسیر نیاز به Android Studio روی کامپیوترت داره (رایگانه ولی حجیمه، چند GB).
مراحل کلی (باید خودت این دستورها رو بزنی، چون به SDK اندروید نیاز داره):

    npm install @capacitor/core @capacitor/android
    npx cap init "Shift Priority" com.tokransit.shiftpriority
    npm run build
    npx cap add android
    npx cap copy
    npx cap open android

آخرین دستور، Android Studio رو باز می‌کنه؛ از منوی Build → Build Bundle(s)/APK(s)
→ Build APK(s) یه فایل .apk می‌سازه که می‌تونی مستقیم روی گوشی نصب کنی
(باید گزینه "نصب از منابع ناشناس" رو در گوشی فعال کنی).


## ۴) آیفون — فایل نصبی واقعی (محدودیت واقعی اپل)
اپل اجازه نمی‌ده یه فایل .ipa رو مستقیم مثل exe یا apk به کسی داد و نصب کرد،
مگر اینکه:
- یک حساب Apple Developer داشته باشی (۹۹ دلار در سال)، و
- با یک مک و Xcode برنامه رو بسازی و از طریق TestFlight یا App Store منتشر کنی.

این محدودیت اپله، نه محدودیت این پروژه. برای آیفون، روش شماره ۲ (PWA /
Add to Home Screen) عملاً بهترین و تنها راه بدون هزینه و بدون مک است.


اگه به مشکلی خوردی، متن دقیق پیغام خطا رو کپی کن و بفرست.
