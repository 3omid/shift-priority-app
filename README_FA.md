## این برنامه چیکار می‌کنه؟

این ابزار برای رانندگان TOK Transit ساخته شده تا از روی فایل اکسل جدول شیفت
(Crew Sheet)، بهترین گروه‌های کاری رو بر اساس سلیقه شخصی هر راننده رتبه‌بندی کنه.

مراحل کار:
1. فایل اکسل شیفت (مثلاً `Mobility Runs_Sep_06_2026.xlsx`) رو آپلود می‌کنی.
2. برنامه خودش ستون‌های Crew #، Type (4DAY/5DAY)، شیفت AM/PM، هفت روز هفته و
   مجموع ساعات رو پیدا می‌کنه.
3. منطقه کاری هر روز (نیومارکت، ریچموند هیل، کالداری، استوفیل، مپل، یا
   آماده‌باش RPT) از روی رنگ سلول اکسل و کدهای STF/MRG/RPT تشخیص داده می‌شه.
4. تو یک لیست اولویت شخصی می‌سازی: مثلاً «اول شیفت PM مهمه، بعد ۴ روزه بودن،
   بعد نیومارکت، بعد داشتن روز آماده‌باش». تا ۱۰ معیار، به هر ترتیبی که بخوای.
5. رتبه‌بندی زنجیره‌ای انجام می‌شه: اول همه گروه‌ها روی معیار ۱ مرتب می‌شن؛
   هرجا مساوی بودن، معیار ۲ تصمیم می‌گیره، و همین‌طور تا آخر لیست.
6. نتیجه: ۵ گزینه برتر با مدال طلا/نقره/برنز و بقیه گروه‌ها زیرش، هرکدوم با
   جزئیات ساعت دقیق هر روز در هر منطقه.
7. می‌تونی چند گروه رو برای مقایسه کنار هم انتخاب کنی، گزارش رو پرینت/PDF یا
   اکسل بگیری.

## زبان‌های پشتیبانی‌شده
فارسی، انگلیسی، هندی — از گوشه بالای صفحه قابل تعویضه.

## چه چیزی برای اجرا لازم داری؟ (بر اساس سیستم)

### ویندوز — دو حالت
- **حالت سریع (بدون نصب دائمی):** فقط Node.js لازمه (`run.bat` رو بزن، خودش
  راهنماییت می‌کنه اگه نصب نبود).
- **فایل نصبی exe واقعی:** `build-exe.bat` رو بزن؛ اولین بار Node.js و
  کتابخونه‌ها لازمن، ولی فایل نهایی (`release` پوشه) رو می‌تونی روی هر
  ویندوزی بدون نیاز به Node.js نصب کنی.

### آیفون (iOS)
اپل اجازه نصب فایل مستقیم (ipa) بدون حساب Apple Developer ($99 در سال) و Mac
+ Xcode نمی‌ده. راه‌حل عملی: نسخه PWA — از Safari، دکمه Share → «Add to Home
Screen». نیاز به اینترنت فقط برای بار اول (بعدش آفلاین هم کار می‌کنه).

### اندروید
- ساده: همون روش PWA (از Chrome، «Add to Home screen»).
- پیشرفته (apk واقعی): نیاز به Android Studio روی کامپیوتر (رایگان، ولی چند
  گیگابایت حجمشه). دستورهای دقیق در همین پوشه، فایل `README.txt`.

### به‌طور کلی نرم‌افزار به این‌ها نیاز داره
- Node.js نسخه ۱۸ به بالا (برای اجرا/بیلد روی کامپیوتر)
- کتابخونه‌های React، Vite، xlsx (SheetJS)، lucide-react — همه از طریق
  `npm install` خودکار نصب می‌شن.
- برای exe ویندوز: Electron و electron-builder (هم از طریق npm).
- اینترنت فقط برای نصب اولیه کتابخونه‌ها لازمه؛ بعد از اون برنامه کاملاً
  آفلاین کار می‌کنه (هیچ داده‌ای به سروری ارسال نمی‌شه، همه پردازش‌ها روی
  همون کامپیوتر/گوشی انجام می‌شه).

## ساختار فایل‌های پروژه
```
shift-priority-app/
├── src/App.jsx        کد کامل برنامه (React)
├── src/main.jsx        نقطه ورود React
├── index.html           صفحه HTML اصلی + تنظیمات PWA
├── public/               آیکون‌ها، manifest.json، service worker
├── electron/main.js    فایل اصلی نسخه دسکتاپ ویندوز
├── package.json          لیست کتابخونه‌ها و دستورها
├── run.bat                 اجرای سریع (حالت توسعه)
├── build-exe.bat        ساخت فایل نصبی ویندوز
├── LICENSE                 مجوز MIT
├── README.txt             راهنمای فنی نصب هر پلتفرم
└── README_FA.md / README_EN.md   همین راهنما، به دو زبان
```

## حریم خصوصی
هیچ داده‌ای (فایل اکسل، اولویت‌ها، نتایج) به هیچ سروری ارسال نمی‌شه؛ همه‌چی
داخل مرورگر/برنامه خودت پردازش می‌شه.
